# DigiFace · دیجی‌فیس

بازار آنلاین لوازم آرایشی و بهداشتی: فروشگاه‌ها کالاهایشان را عرضه می‌کنند، مشتری می‌خرد و پیک در شهر تحویل می‌دهد.

An online marketplace for beauty and personal-care products: shops list what they sell, customers order, and couriers deliver in the city.
